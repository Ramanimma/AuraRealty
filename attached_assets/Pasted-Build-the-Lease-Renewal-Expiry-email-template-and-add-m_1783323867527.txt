2. Create POST /api/admin/send-lease-renewal-email in server/index.ts, protected by verifyAdmin:

Accepts { leaseId: string } in the request body
Fetches the full lease record from lease_reminders by ID
Determines the assigned sender from the lease's owner1 email — check master_clients for a matching email to get their sender_email. If not found, default to ramanimma@texasrealtyhub.com
Sends 3 emails using buildBrandedEmail + the three template functions above:

To owner1_email (owner version) — from the assigned sender
To tenant1_email (tenant version) — from the assigned sender
If owner2_email exists, send owner version to them too
If tenant2_email exists, send tenant version to them too
To the assigned sender's email address (agent notification version) — from ramanimma@texasrealtyhub.com as a system notification


Log the entire send as one campaign entry in email_campaigns (type: "lease_renewal") with all recipients logged in email_campaign_recipients
Return { ok: true, sent: number, failed: number } or descriptive error

Returns the tenant version HTML (as the primary preview) wrapped in buildBrandedEmail with isPreview: true
Same blob/new-tab pattern as birthday preview
