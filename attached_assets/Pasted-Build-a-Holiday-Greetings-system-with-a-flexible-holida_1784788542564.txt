Build a Holiday Greetings system with a flexible holiday management admin page, email templates, and automation.

1. Create Supabase table:

sql
CREATE TABLE holidays (
  id uuid DEFAULT gen_random_uuid() PRIMARY KEY,
  name text NOT NULL,
  type text NOT NULL DEFAULT 'us',
  holiday_date date NOT NULL,
  year int NOT NULL,
  is_active boolean DEFAULT true,
  greeting_email_sent_at timestamptz DEFAULT NULL,
  created_at timestamptz DEFAULT now()
);
ALTER TABLE holidays ENABLE ROW LEVEL SECURITY;

3. Backend endpoints in server/index.ts, all protected by verifyAdmin:

GET /api/admin/holidays — returns all holidays ordered by date
POST /api/admin/holidays — create new holiday
PUT /api/admin/holidays/:id — update holiday (name, date, type, is_active)
DELETE /api/admin/holidays/:id — delete holiday
POST /api/admin/send-holiday-greeting/:id — manually send greeting for a specific holiday
GET /api/admin/preview-holiday-greeting/:id?audience=us|indian — preview the greeting email

5. Sending logic for POST /api/admin/send-holiday-greeting/:id:

Fetch the holiday by ID
Determine audience based on type:
us → send to ALL clients where greeting_preference != 'none' and email_opted_out = false
indian → send to clients where greeting_preference = 'indian_and_us' and email_opted_out = false
For each client, send using their sender_email (Rama or Swetha)
Log to email_campaigns and email_campaign_recipients
After successful send, update greeting_email_sent_at on the holiday record (duplicate protection)
Return { sent, failed, skipped }
